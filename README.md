# NoSleep - Windows 防休眠工具

NoSleep 是一个轻量级 Windows 防休眠工具，用于在指定时间内保持系统唤醒，并通过系统托盘显示倒计时。

## 特性

- 纯 Win32 API 实现，无外部运行时依赖
- 清晰的中文输入界面，支持高 DPI 和多显示器缩放
- 常用时长快捷选择：30 分钟、1 小时、90 分钟、2 小时、3 小时、4 小时
- 支持自定义分钟数，范围 1-1440 分钟
- 托盘提示显示剩余时间和结束时刻，例如"还剩 1 小时 23 分钟（至 14:30）"，每分钟准时刷新
- 双击托盘图标（或用键盘选中后按 Enter）查看精确到秒的剩余时间
- 右键托盘（或按菜单键）可查看状态、重新设置时长（含自定义）、切换"保持屏幕常亮"或退出
- 可选"允许关闭显示器"：只阻止系统睡眠，屏幕可以按电源计划正常熄灭
- 再次运行程序时不会报错，而是把参数转交给正在运行的实例（重设时长或打开设置窗口）
- 使用带原因说明的电源请求，管理员执行 `powercfg /requests` 可看到"NoSleep：保持唤醒至 14:30"
- 手动睡眠 / 合盖进入睡眠或休眠时，自动解除防休眠并退出
- 时间到后自动退出，并恢复系统正常睡眠行为
- 开机自启时若任务栏尚未就绪，会自动重试添加托盘图标
- 支持高对比度主题；托盘与标题栏使用匹配尺寸的清晰图标

## 使用方法

### 直接运行

```bash
# 打开中文输入窗口，选择快捷时长或输入自定义分钟数
nosleep_pure.exe

# 通过命令行直接指定时长，单位为分钟
nosleep_pure.exe 60

# 只阻止系统睡眠，允许显示器按电源计划关闭
nosleep_pure.exe 60 --allow-display-off
```

已有实例在运行时再次启动：带时长参数会直接把正在运行的计时重设为该时长；不带参数则打开它的设置窗口。

### 托盘操作

1. 鼠标悬停托盘图标：查看剩余时间和结束时刻。
2. 双击托盘图标：查看精确到秒的剩余时间。
3. 右键托盘图标：菜单顶部显示当前状态，可选择 `重新设置时长`、`保持屏幕常亮` 或 `退出`。
4. `重新设置时长` 子菜单可将计时直接重置为常用时长，或选择 `自定义...` 输入任意分钟数。
5. 手动让系统睡眠、或合盖进入睡眠/休眠时，NoSleep 会自动退出（无需先手动关闭）。

键盘操作：按 `Win + B` 选中通知区域，用方向键移到 NoSleep 图标，按 `Enter` 查看剩余时间，按菜单键或 `Shift + F10` 打开菜单。

## 编译方法

需要 MinGW-w64 编译器（gcc、windres）和 make。编译参数统一在 `Makefile` 中维护：

```bash
# Windows（MSYS2 / MinGW）
make

# Linux 交叉编译
make CROSS=x86_64-w64-mingw32-
```

也可以在 PowerShell 中运行（内部调用 `make` 或 `mingw32-make`）：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

## 文件说明

- `nosleep_win32.c` - 主程序源代码
- `nosleep.rc` - Windows 资源文件（图标、manifest、版本信息）
- `nosleep.manifest` - 视觉样式和高 DPI 配置
- `nosleep.ico` - 应用图标
- `Makefile` - 构建脚本（编译参数的唯一来源）
- `build.ps1` - PowerShell 构建入口（调用 make）
- `README.md` - 项目说明文档

## 系统要求

- Windows 7 或更高版本，无需安装额外运行时（程序只依赖系统自带的 `msvcrt.dll`）
- 若自行使用 MSYS2 的 UCRT64 工具链编译，Windows 7/8.1 需要预先安装 Universal CRT 更新（KB2999226）
